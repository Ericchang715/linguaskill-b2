# Linguaskill B2 英語練習工作台

繁體中文的平日練習站，首頁依臺灣時間顯示週一至週五上午 10:00。內附 2026 年 11 月 9 日至 13 日五份自編題組，涵蓋高等教育、職場溝通、運動生活與學習策略。考試題型可參考[劍橋英語官方說明](https://www.cambridgeenglish.org/tw/exams-and-tests/linguaskill/information-about-the-exam/exam-formats-and-task-types/)。

## 在 GitHub Pages 發佈

1. 解壓縮，把解出的檔案與資料夾放到 GitHub 儲存庫的 `main` 分支根目錄。確認 `index.html`、`.nojekyll`、`assets/`、`js/` 與 `data/` 位於同一層。
2. 在儲存庫開啟 **Settings → Pages**。將 **Source** 選為 **Deploy from a branch**，選擇 **main** 與 **/(root)**，按 **Save**。
3. 發佈完成後，從 Pages 設定頁按 **Visit site**。所有網站檔案採相對路徑，儲存庫子路徑也適用。

部署包內的 HTML、CSS、JavaScript 與 JSON 可直接上傳。[GitHub Pages 官方發佈說明](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

若要先在電腦試用，可在解壓縮後的目錄執行 `python3 -m http.server 8000`，開啟 `http://localhost:8000/`。以 HTTP 開啟時，瀏覽器才能讀取程式模組與題庫。

## 每天怎麼練

- 從總覽開始建議題組，或用日期、主題、題型與完成狀態查找。點每週安排的日期可直接套用該日篩選。選定題型時，完成狀態只代表該題型。
- 完形填空有選擇題與輸入題。送出前的答案會存成草稿。送出後可看分數、參考答案、全文翻譯與逐題解析。
- 字彙練習每個單字顯示 3 次。唸完一次點一下，搭配繁中意思、B2 英文例句與例句翻譯。所有單字練完再按「完成字彙練習」。
- 「練習歷程」保留歷次結果與備註。「錯題複習」保留答錯時的題目與解析，重做同一版本並答對就會標為已訂正。「待複習單字」可標為已複習，也可移回待複習。

## 新增與編輯題庫

1. 選「新增每週練習」，載入或下載範本，把多日題組放進同一個 JSON。已經有每日練習文字時，可複製整理指令，附上日期與原文交給 ChatGPT，再把 JSON 貼回工作台。
2. 選「匯入一週題目」。完全相同的題組會略過。若 ID 相同且內容不同，請先在「題庫管理」編輯，或為新題組改用新的 ID。
3. 單份題組可直接用表單新增或編輯。選擇填空的選項每行填一個，輸入題的選項留空。題庫內的「匯出題庫」可下載完整 JSON。

要更新部署版，用匯出的 `practice-sets.json` 取代儲存庫的 `data/practice-sets.json`，再提交至發佈分支。也可直接依 [資料格式](./DATA-FORMAT.md) 修改。若同一瀏覽器已有該題組的自訂版本，可在編輯視窗選「使用網站版本」切換到新部署的版本。題目與正解改動後會以新版本追蹤進度，原作答仍留在歷程。

## 備份與移轉

在「使用說明與備份」選「匯出學習備份」。備份含瀏覽器內新增或修改的題組、草稿、完成紀錄與收藏單字。換裝置、瀏覽器或網址後，可選檔或貼上備份內容。先按「檢查備份」，核對摘要後再按「確認還原」。

要改備註，可在練習歷程開啟單筆紀錄。要調整其他學習紀錄，可先保留原始備份，再依資料格式編輯一份副本並還原。部署時上傳網站檔和題庫，個人學習備份請自行保管。
